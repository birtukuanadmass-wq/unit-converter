Meለካ

Converter About Privacy

Why this exists

Meለካ is a small, free converter built to make everyday conversions — length, weight, temperature, speed, and Ethiopian Birr exchange — quick and clutter-free. No account, no sign-up, no app to install. Type a number, get an answer.

What it converts

  • Length: millimeters through miles
  • Weight: milligrams through metric tons
  • Temperature: Celsius, Fahrenheit, Kelvin
  • Speed: m/s, km/h, mph, knots
  • Currency: Ethiopian Birr against USD, EUR, and GBP, using live exchange rates

How the currency rates work

The Birr converter pulls live exchange rate data each time you open that tab. If a live rate can't be fetched — for example, if you're offline — the page falls back to an approximate rate so it still gives you a usable answer.

Who built it

Meለካ is an independent project built and maintained by its creator, hosted for free on GitHub Pages.
